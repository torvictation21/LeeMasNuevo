# Componentes de Lee+

## shared
- `AppHeader.vue`: marca, racha, tema, notificaciones, perfil y configuración.
- `AppNavigation.vue`: barra de navegación para escritorio y móvil.
- `PagePlaceholder.vue`: estructura temporal para páginas que se construirán después.

## progreso
- `ProgressPage.vue`: contenedor y estado global de la vista de progreso.
- `ProgressHero.vue`: titular y resumen del perfil.
- `ProgressJourney.vue`: nivel y barra de progreso.
- `ProgressAchievements.vue`: medallas y logros.
- `CurrentReading.vue`: historia en curso y acción de lectura.

## desktop/progreso
- `DesktopProgressLayout.vue`: disposición de los módulos para pantallas grandes.

## mobile/progreso
- `MobileProgressLayout.vue`: disposición equivalente optimizada para móvil.
